# Postman Collection

Files in this folder:
- `hackathon-api.postman_collection.json`
- `hackathon-api.postman_environment.json`

## Import

1. Open Postman.
2. Import the collection JSON.
3. Import the environment JSON.
4. Set `baseUrl` if your backend is not running on `http://localhost:3000`.
5. Paste your JWT into `token` if you want to send bearer auth headers.

## Notes

- This collection includes the documented HTTP routes from the backend.
- WebSocket gateways are not included in the Postman collection.
